# Vehicle Fusion

A Multi-Agent Vehicle Detection and Fusion System using YOLOv8 and Edge Computing.

## Features

- Multi-camera synchronized video processing
- YOLOv8 vehicle detection
- Detection packet generation
- Edge-server communication
- Multi-agent fusion
- World-coordinate projection
- Evaluation using ground truth
